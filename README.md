# 💬 ChatApp iOS — Swift

**ChatApp iOS** is a messaging application built for iOS using Swift. The project focuses on creating a clean chat interface and implementing messaging features using native iOS technologies.

## 🚀 Features

* 💬 Chat interface and message bubbles
* 👤 User profile interface
* 📱 Native iOS user interface
* 📩 Messaging screen
* 🎨 Clean and user-friendly design

## 🛠️ Technologies Used

* Swift
* UIKit / SwiftUI
* Xcode
* Auto Layout (if applicable)
* Firebase / REST API (if integrated)
